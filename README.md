
# Core Programming Summary

## 1. Arrays

* Fixed-size, ordered collection of elements of the same type.
* Indexed starting from 0.
* Useful for storing and accessing multiple values efficiently.
* Example: `int[] nums = new int[5];`

## 2. Strings

* Sequence of characters, often immutable in many languages (e.g., Java).
* Represent text data.
* Support operations like concatenation, comparison, and substring extraction.

## 3. Methods

* Blocks of code that perform specific tasks and can be reused.
* Defined with a name, return type, parameters, and body.
* Help organize code and avoid repetition.
* Can be **void** (no return) or return values.

## 4. Built-in Methods

* Predefined functions provided by programming languages or libraries.
* Common string methods: `.length()`, `.substring()`, `.indexOf()`, `.toUpperCase()`, `.equals()`.
* Common array methods (in some languages): sorting, searching, copying (e.g., `Arrays.sort()` in Java).
* Help simplify common programming tasks without reinventing the wheel.
